# Netflix Content Analysis 📊

An interactive Power BI dashboard that explores Netflix movies and TV shows through data visualization.

### Key Insights
- Content distribution by country.
- Analysis of movies and TV shows.
- Genre-wise content exploration.
- Rating-wise content analysis.

### Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization

### Project File
`Netflix-Content-Analysis.pbix`

Open the PBIX file in Power BI Desktop to explore the interactive dashboard.
